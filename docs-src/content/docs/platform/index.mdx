---
title: Platform user guide
description: Understand what the platform adds to the Decoy pipeline workflow.
---

The Decoy platform runs the same pipeline model as the CLI. It adds shared
connectors, managed jobs, authorization, reviews, schedules, notifications, and
operational records.

Use the CLI for local development, test fixtures, and CI. Use the platform when
a team needs shared data access and managed operations.

## Platform workflow

```text
connect -> profile -> configure -> preflight -> run -> review -> automate
```

Start with the platform workflow. Read the scheduling guide after a manual run
succeeds.
