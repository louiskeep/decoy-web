---
title: Differential privacy in Decoy
description: Understand Decoy's fit-wide privacy budget and generated-data guarantee.
---

Decoy can fit a differentially private marginal snapshot and generate rows from
it. The guarantee uses add-or-remove-one-row adjacency.

## Two required declarations

The fit command declares the release budget and the allowed data carriers:

```bash
decoy fit patients.csv \
  --output patients.dp.json \
  --epsilon 1.0 --delta 0.000001 \
  --dp-number age:0:120 \
  --dp-text diagnosis_code
```

This is one fit-wide `(epsilon, delta)` request. Decoy's accountant composes the
internal measurements and records the resulting `epsilon_total` and
`delta_total` in the snapshot.

The generation pipeline declares the maximum composed budget it accepts:

```yaml
global_settings:
  seed: 42
  dp:
    epsilon: 1.0
    delta: 0.000001
```

This block is an enforced ceiling, not a label. The compiler verifies each
distinct DP release by its release ID. It rejects the pipeline when the composed
snapshot spend exceeds either ceiling.

## What the guarantee covers

The guarantee covers the fitted marginal release and deterministic
post-processing from it, including synthetic sampling. It does not cover:

- masking existing rows;
- joint or conditional distributions;
- dates, free text, or undeclared source columns;
- schema and column names, which are treated as public metadata;
- multiple records that belong to one person as one privacy unit.

The privacy unit is one row. A person with many rows can contribute more than
one unit.

## Budget and utility

Lower epsilon usually adds more noise and reduces fidelity. Delta is the
approximate-DP failure parameter. Choose both values through your privacy
review; Decoy does not select an organizationally safe budget for you.

Multiple distinct DP snapshots in one pipeline compose. Reusing one release in
several columns does not create a new release ID, but consuming another DP
snapshot adds its recorded spend to the pipeline ceiling check.

DP is not anonymization and does not certify an output for unrestricted
publication. Read [Differentially private generation](/docs/reference/generation/differential-privacy)
for the exact configuration and [Security, privacy, and compliance limits](/docs/reference/limits)
for the boundary of the claim.
