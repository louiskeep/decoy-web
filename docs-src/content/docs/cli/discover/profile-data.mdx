---
title: Pre-scan your data
description: Run a pre-scan to inspect table shape, field statistics, and possible sensitive fields before you write a pipeline.
---

Pre-scan a source file before you select masking strategies. A pre-scan reports
possible sensitive fields. It does not classify or change the data.

## Pre-scan one file

```bash
decoy pre-scan customers.csv --show-fields
```

By default, Decoy pre-scans the first 10,000 rows. Use `--rows 0` to read the
full file:

```bash
decoy pre-scan customers.csv --rows 0 --show-fields
```

Use JSON output in automation:

```bash
decoy pre-scan customers.csv --show-fields --output scan.json
```

The saved scan contains field names, data types, null rates, distinct counts, and
possible sensitive-field flags. It does not contain raw cell values.

## Review the result

For each flagged field, answer these questions:

1. Does the field contain direct or indirect identifiers?
2. Must equal source values remain joinable after masking?
3. Must the output preserve format, range, or distribution?
4. Must an authorized user reverse the masked value?

Use [Choose a masking strategy](/docs/cli/masking/choose-a-strategy) to map
those answers to a strategy.

## Create a reviewed pipeline

```bash
decoy init customers.csv --output pipeline.yaml
```

`decoy init` scans the file and adds a `# REVIEW:` comment for each suggested
column rule. Read every comment. Change any rule that does not match the data or
your policy.

Then validate the pipeline:

```bash
decoy validate config pipeline.yaml
decoy validate preflight pipeline.yaml
```
