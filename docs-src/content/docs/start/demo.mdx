---
title: Run the demo
description: Run a bundled profile-and-mask example before you use your own data.
---

`decoy demo` runs a complete example with bundled data. Use it after installation
to see the workflow without writing a pipeline.

## Run the demo

```bash
decoy demo
```

Decoy writes all artifacts to `./decoy_demo/` by default. Use `--dir` to select
another directory.

```bash
decoy demo --dir first-run
```

The demo creates these files:

- `customers.csv`: the sample source.
- `pipeline.yaml`: the reviewed example pipeline.
- `customers_masked.csv`: the masked output.
- A saved data profile for the source.

## Inspect the result

```bash
head -3 decoy_demo/customers.csv
head -3 decoy_demo/customers_masked.csv
```

Compare the two files. The demo replaces direct identifiers and leaves reviewed
non-sensitive fields unchanged.

Open `decoy_demo/pipeline.yaml`. This file shows the exact configuration that
produced the output.

## What the demo teaches

The demo follows the same workflow as a real run:

```text
profile -> review pipeline -> run -> inspect output
```

The profile does not make a final classification. A user must review each
suggestion before a real run.
