Decoy has two primary workflows:

- **Mask data** when you have source data and need a safer copy.
- **Generate data** when you need new test data that contains no source rows.

The CLI runs both workflows from a pipeline configuration. The platform adds
shared connectors, managed jobs, access controls, schedules, reviews, and
operational records.

## Recommended path

1. [Install Decoy](/docs/start/install) and run `decoy doctor`.
2. [Run the demo](/docs/start/demo) to see a complete scan-and-mask run.
3. [Mask your first CSV](/docs/start/quickstart) with your own small file.
4. [Generate your first dataset](/docs/start/generate) without source data.

Each tutorial uses the same workflow:

```text
scan -> configure -> validate -> run -> report
```

After the tutorials, use the [CLI user guide](/docs/cli) for task instructions.
Use [Reference](/docs/reference) to look up commands, fields, and supported
variants.
