---
title: Generate your first dataset
description: Create synthetic rows from a small generation pipeline, then inspect the output.
---

Generation creates new rows. It does not require a source file.

## 1. Create the pipeline

Save this file as `generate.yaml`:

```yaml
version: 1
global_settings:
  seed: 42
sources: {}
tables:
  - name: employees
    row_count: 100
    generate_columns:
      - name: employee_id
        type: sequence
        start: 1000
        step: 1
      - name: first_name
        type: faker
        faker_type: first_name
      - name: department
        type: categorical
        categories: [Engineering, Sales, Support]
        weights: [0.5, 0.3, 0.2]
targets:
  employees:
    type: file
    format: csv
    path: ./employees.csv
```

## 2. Validate and run

```bash
decoy validate config generate.yaml
decoy validate preflight generate.yaml
decoy run generate.yaml --mode generate --evidence-out evidence.json
```

## 3. Inspect the output

```bash
head -5 employees.csv
wc -l employees.csv
```

The output contains 100 synthetic rows and one header row.
