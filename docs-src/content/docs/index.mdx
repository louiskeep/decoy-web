Decoy masks sensitive data and generates synthetic test data. The CLI runs local
pipeline configurations. The platform adds shared operations, governance, and
scheduling.

## New to Decoy?

Follow the [Start here](/docs/start) path. It takes you from installation to a
reviewed output:

```text
install -> demo -> scan -> configure -> validate -> run -> report
```

## Choose your goal

- **[Mask existing data](/docs/start/quickstart)**: scan a CSV, review a
  pipeline, and create a masked copy.
- **[Generate synthetic data](/docs/start/generate)**: create new rows from a
  generation configuration.
- **[Use the CLI](/docs/cli)**: follow the complete command workflow and common
  task guides.
- **Use the platform**: add shared connectors, managed runs, access controls,
  schedules, reviews, and operational records. Platform guides remain private
  until the platform release.
- **[Look up a detail](/docs/reference)**: find a command, configuration field,
  strategy, provider, relationship type, or validation method.
