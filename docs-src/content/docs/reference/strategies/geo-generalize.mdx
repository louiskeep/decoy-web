---
title: geo_generalize
description: Generalize a location through a cascade of coarser levels.
---

Generalizes a ZIP or a latitude/longitude through an ordered cascade of coarser
levels. A level is kept only if its cell holds at least `k_threshold` rows,
otherwise the value drops to the next level; the cascade ends with `suppress`, so
no output ever identifies a small group.

## Settings

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | string | required | `zip` or `lat_lng` |
| `cascade` | list of string | required | Ordered levels, ending with `suppress`. For `zip`: `zip5`, `zip3`, `state`. For `lat_lng`: `h3_resolution_9`, `h3_resolution_7`, `h3_resolution_5` |
| `k_threshold` | integer | `20000` | A level is kept only if its cell holds at least this many rows |

For the full parameter set, run `decoy strategies inspect geo_generalize`.

## Example

```yaml
- name: patient_zip
  strategy: geo_generalize
  provider_config:
    type: zip
    cascade: [zip5, zip3, suppress]
```
