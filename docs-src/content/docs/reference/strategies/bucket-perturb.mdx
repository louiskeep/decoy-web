---
title: bucket_perturb
description: Snap a date to a deterministic position in its week, month, or quarter.
---

Moves a date to a deterministic position inside its ISO week, calendar month, or
calendar quarter, so the date shifts within a bounded period and the same input
always lands the same way. This is a date strategy; it does not apply to numbers.

## Settings

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `bucket` | string | required | The period to snap within: `week`, `month`, or `quarter` |
| `date_format` | string | none | Format string for the date column |

For the full parameter set, run `decoy show strategy bucket_perturb`.

## Example

```yaml
- name: admit_date
  strategy: bucket_perturb
  provider_config:
    bucket: month
```
