Work with healthcare code sets

Use ICD-10, HCPCS, NDC, and custom code set columns for masking and generation.

Decoy includes public-domain healthcare code sets (ICD-10-CM, HCPCS Level II, NDC) and lets you upload your own. This page covers how to configure and use code set columns.

What is a code set column?

A code set column contains standardized medical codes (diagnoses, procedures, billing codes). Decoy can:

  • Mask: replace real codes with other valid codes from the same corpus
  • Generate: sample synthetic codes from a distribution fitted off your source
  • Preserve structure: keep codes valid across related tables with foreign keys

Built-in code sets

Decoy ships three healthcare code set corpora:

Code SetTypeCodesUse Case
ICD-10-CMDiagnosis74,719Outpatient/inpatient diagnoses
HCPCS Level IIService/Supply8,725Outpatient procedures, durable medical equipment
NDCDrug217,019Prescription and OTC medications

All are public domain (no license restrictions). Each corpus includes optional chapter organization for hierarchical masking (ICD-10-CM only; HCPCS and NDC are flat).

Mask with a code set

Use the code_set strategy to replace codes with valid alternatives:

Code set masking modes

code_set with no extra options (above): Replace each code with a uniform random valid code from the corpus. All 74,719 ICD-10 codes are equally likely.

code_set with chapter_preserve: true: Keep codes in the same chapter (e.g., diagnoses starting with I for circulatory). ICD-10 chapter structure is hierarchical (I00-I99 = circulatory system); this option masks within chapter.

code_set with allow_real_categories: true (non-DP only): Sample from the observed frequency distribution of codes in your source, not uniform random. If your data has 50% hypertension (I10) and 30% diabetes (E11), the masked output preserves these proportions.

Generate synthetic codes

Use type: statistical with a code set column:

This fits a distribution snapshot of the source codes and samples from it. The generated codes match your source frequency (e.g., hypertension codes appear at the same rate as in the original data).

Generation options

allow_real_categories: false (default under DP): Generalize rare categories to __other__. Use this if your source has many low-frequency codes and you want to protect them.

allow_real_categories: true (non-DP only): Retain all observed codes, including rare ones. Generated data preserves exact frequency distribution.

high_cardinality: true: Retain the full vocabulary of observed codes (all 1,000+ codes if present in your source). Without this, Decoy collapses codes into an __other__ bucket if there are too many distinct values. Set this for code-set columns which naturally have high cardinality.

Upload a custom code set

For codes not in the built-in sets (proprietary billing codes, internal coding schemes), upload your own:

Custom corpus format

Your corpus must be a Parquet file with at least these columns:

Required:

  • code: Non-null, non-empty, unique string identifier
  • description: String (can be empty)

Optional:

  • chapter: String or int; enables chapter_preserve: true

Store the file locally and reference it as customer:/absolute/path/to/file.parquet. Decoy validates the corpus at load time and fails closed if the schema is invalid.

Troubleshooting

Error: code_set_corpus_null_code or code_set_corpus_empty_code

Output doesn't preserve my frequency distribution

Check that allow_real_categories: true is set. Without it, Decoy masks to uniform random codes (anonymization mode). With it, frequency is preserved.
