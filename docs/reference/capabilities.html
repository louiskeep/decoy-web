Validation and safety

  • Fail-closed: configuration errors are rejected at compile time, not run time.
  • Schema validation with descriptive errors.
  • Referential-integrity checks: FK cycles, dangling references, and invalid masking topologies are caught before any data is written.
  • DP budget enforcement: declared epsilon/delta ceilings are checked.

Limits

See Security, privacy, and compliance limits for what Decoy does not cover (masked output carries no DP guarantee; DP is per-column marginals on generated data only; composite FKs are not sampled tuple-wise).
