# decoy-web docs

In-repo documentation for `decoy-web` (the marketing site). This repo owns
**web-scoped** docs only: `superpowers/specs/` + `superpowers/plans/` (design
specs and implementation plans for site work) and `audit/` (site audits).

The single cross-repo roadmap for all of Decoy is
`decoy-platform/docs/ROADMAP.md`, which indexes web items too. Do not start a
separate web roadmap, next-up, or todo doc.

Follow the shared documentation lifecycle (plan → build → promote-to-reference +
archive on ship) in `/home/cam/dev-rules/documentation.md`. Web implementation
plans belong in `docs/plans/` once that convention is adopted here; today they
live under `docs/superpowers/plans/`.
