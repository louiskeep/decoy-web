---
title: text_redact
description: Find PII in free text and redact it.
---

Detects spans in free text (pattern detectors plus optional NER) and replaces each
with a fixed token, so the sensitive spans are removed rather than swapped for
synthetic text. Use `text_mask` to replace spans with realistic values instead.

## Settings

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `detectors` | list of string | see inspect | Pattern detectors to run over the text |
| `ner` | boolean | `false` | Also run named-entity recognition |
| `entities` | list of string | none | NER entity types to catch (person, location, and similar) |
| `model` | string | default | The NER model to load |
| `token` | string | `[REDACTED]` | The fixed replacement for each span |
| `label_token` | boolean | `false` | Tag the token with the detected type |

For the full parameter set, run `decoy strategies inspect text_redact`. See also
[Redact text with NER](/docs/how-to/redact-text-with-ner).

## Example

```yaml
- name: free_text
  strategy: text_redact
  provider_config:
    ner: true
    entities: [person]
    label_token: true
```
