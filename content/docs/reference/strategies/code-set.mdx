---
title: code_set
description: Replace a code with another valid code from the same set.
---

Swaps a value for a real code from a corpus, so the output is still a valid code.
`chapter_preserve` keeps the replacement in the same chapter as the original.

## Settings

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `code_set` | string | required | The corpus: `icd10`, `hcpcs`, `ndc`, or `mcc` |
| `chapter_preserve` | boolean | `false` | Keep the replacement in the original code's chapter |
| `corpus_source` | string | `shipped` | `shipped`, or `customer:<absolute_path>` to use your own set |
| `corpus_source_version` | string | none | Pin an expected corpus release id |

For the full parameter set, run `decoy strategies inspect code_set`. See also
[Work with healthcare code sets](/docs/how-to/work-with-healthcare-code-sets).

## Example

```yaml
- name: diagnosis
  strategy: code_set
  provider_config:
    code_set: icd10
    chapter_preserve: true
```
