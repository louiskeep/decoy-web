---
title: Synthetic data providers
description: The named value sources for the faker strategy and generation type.
---

A provider is the value source behind the `faker` mask strategy and the `faker`
generation type. Set it with `provider:` on a column. There are 34, across people,
addresses, identifiers, and composites. The `decoy_native` providers are
deterministic and checksummed; the faker ones are random per run unless the column
sets `deterministic: true`.

## People

| Provider | Generates | Backend |
| --- | --- | --- |
| `person_name` | A full name | faker |
| `person_first_name` | A first name | faker |
| `person_last_name` | A last name | faker |
| `person_full_name` | A full name | faker |
| `person_email` | An email address | faker |
| `person_phone` | A phone number | faker |
| `person_dob` | A date of birth | faker |

The name and email providers use faker by default; install the `mimesis` extra to
back them with mimesis instead.

## Composites

Composites keep several fields coherent with each other (a city that matches its
state and ZIP). Pair them with `coherent_with` on the columns they cover.

| Provider | Generates | Backend |
| --- | --- | --- |
| `composite_person` | A coherent person record | composite |
| `composite_name_email` | A name with a matching email | composite |
| `composite_address` | A coherent address | composite |
| `composite_city_state_zip` | A matching city, state, and ZIP | composite |
| `composite_provider` | A coherent provider record | composite |
| `composite_custom` | A user-defined coherent set | composite |

## Identifiers (deterministic)

These are `decoy_native`, deterministic and checksummed, so the same input maps to
a valid, stable identifier.

| Provider | Generates | Unique |
| --- | --- | --- |
| `synthetic_ssn` | A synthetic SSN | yes |
| `synthetic_npi` | A National Provider Identifier | yes |
| `synthetic_mrn` | A medical record number | yes |
| `synthetic_icd10` | An ICD-10 diagnosis code | no |
| `synthetic_ndc` | A National Drug Code | yes |
| `synthetic_pan` | A primary account (card) number | yes |
| `synthetic_iban` | An IBAN | yes |
| `synthetic_ein` | An Employer Identification Number | yes |
| `synthetic_cusip` | A CUSIP security identifier | yes |

## Generic

| Provider | Generates | Backend |
| --- | --- | --- |
| `lorem_text` | Placeholder text | faker |

| `random_int_range` | An integer in a range | faker |

## Usage

```yaml
# masking: replace a column with a provider value
- name: email
  strategy: faker
  provider: person_email

# generation: a synthetic column from a provider
- name: npi
  type: faker
  faker_type: synthetic_npi
```
